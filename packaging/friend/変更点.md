# 変更点

## 2.0.1

- `cleanup_old.bat`（Windows）と `cleanup_old_mac.command`（Mac）だけで、Rust 版バイナリの自動取得（SHA-256 検証つき）→ 旧 Python 版の停止 → 不要な旧環境・ファイルの削除 → 自動起動の切り替え・再起動まで一括で完了するようにしました
- `start_client.bat` に `onseiman.exe` があればそのまま Rust 版を起動するよう対応しました

## 2.0.0

Rust 版（Windows x64・macOS Apple Silicon）を追加しました。これまでの Python 版と設定・辞書・履歴（`config.json`・`dict.json`・`logs/`）はそのまま共有できます。

- Rust 版クライアント本体（`onseiman-windows-x64.exe` 約 4.5MB / `onseiman-macos-arm64`）を追加しました。Python の準備なしで起動でき、既存の管理画面（`client/web/`）をそのまま使えます
- Rust 版認識サーバー（`onseiman-server-windows-x64.exe` 約 3.5MB / `onseiman-server-macos-arm64`）を追加しました。Mac の `server_mac.command`（`server/setup_macos.sh`）は Rust 版サーバーがあれば Python なしで自動起動を登録します
- トレイアイコン・フォーカスを奪わない録音中カプセル・録音中の他アプリ音量一時ミュート・LAN サーバー自動探索・再認識・無音自動停止・macOS `CGEventTap` グローバルホットキーを実装しました
- `cleanup_old.bat` / `cleanup_old_mac.command` を更新し、Rust 版が入っている環境では不要になった旧 Python 環境（`.venv`・`tools/python`・`tools/bin` 等）も確認のうえで片付けられるようにしました
- GitHub Actions で Windows x64・macOS arm64 の両方を自動テスト＆ビルドし、`SHA256SUMS` つきで配布します

## 1.2.33

守りを固めました（使い方は変わりません）。

- 認識役: 長さを言わない送り方で大きなデータを送り続けられると、ディスクがいっぱいになるまで受け取っていました。上限で止めるようにしました
- 認識役: ブラウザで開いたよそのサイトから、預かった辞書を読み書きされないようにしました（IP アドレスでつないだ要求だけを受け付けます）
- 認識役: 縮めてある WAV を開いて記憶を使い切らないよう、上限の長さまでしか開かないようにしました。同時に聞き取るのは 4 件まで、預かる辞書は 50 個までです
- アプリ: 認識役から返ってきた文に改行などが混ざっていても、入力しないようにしました（入力先で Enter を押したことにならないように）
- アプリ: 入力のあとの手直しを見る仕組みが、パスワード欄を読まないようにしました
- アプリ: AI の API キーが違うときに、会社の返事（キーの一部が入ることがある）を画面と記録に出さないようにしました
- 更新と準備: zip を開くときに、決めた場所の外へファイルを書かれないようにしました

## 1.2.16

- **GPU で聞き取る版**を足しました。NVIDIA の GPU（RTX など）がある Windows を認識役にするとき、
  `server_windows.bat` のかわりに `server_gpu.bat` をダブルクリックします
  - 聞き取りに Haas-ja（Third Intelligence の日本語の聞き取り AI）を使います。いまの聞き取り（CPU で聞き取る版）より、
    聞き間違いがずっと少なくなります（「文字起こし」「推察して」「高画質化」なども正しく出ます）。1 回の聞き取りは 0.05 秒ほどです

  - 辞書の優先語も効きます。英字の略語（CPU・LLM など）は大文字で入ります
  - GPU で聞き取る版につないでいるときは、30 秒近い話も区切らずに聞き取ります
- 短い話（一度に聞き取れる長さの 85% まで）は、区切らずに通しで聞き取るようにしました。
  区切ると前後のつながりが切れて聞き間違いが増え、区切り目に「。」も入っていました
- 認識役のパソコンも、この版にしてください（一度だけ）

  - タスクトレイのメニューも「新しい版にする」に変わります
  - 設定・辞書・履歴はそのまま残り、前の版は `backup` フォルダに残ります
- `update.bat` が、ほかの場所に置いた OnseiMan が動いているだけでも「動いています」と止まっていたのを直しました
- この版にするときだけは、これまでどおり `update.bat` で入れ替えてください（次からはお知らせから更新できます）

## 1.1.0

- 辞書（優先語・置き換え・言いよどみ・定型文）を、何台かのパソコンで自動で合わせられるようにしました。
  「設定」→「辞書をほかのパソコンと合わせる」で、預け先を選びます
  - 認識役のパソコンに預ける（「別のパソコン」で認識しているとき）

  どれか 1 台で登録・削除すると、ほかのパソコンにも入ります。それぞれで登録していた言葉は、初めて合わせたときに足し合わされます
- 認識役のパソコンも新しい版にしてください（辞書を預かれるようになります）
