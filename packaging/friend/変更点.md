# 変更点

## 1.0.3

- `install_client.bat` が失敗する不具合を直しました（1.0.1・1.0.2 で、部品が入らず日本語の行がエラーになっていました）
- Python を自分で入れなくてもよくなりました。必要なものは、OnseiMan のフォルダの中に自動で用意します
- サーバー用（Windows）の準備も同じ仕組みにしました

## 1.0.2

- 安全のための直し
  - 設定画面を、ほかのサイトから操作・のぞき見・埋め込みされないようにしました
  - 認識用のデータが本物かどうかを、ダウンロードのあとに確かめるようにしました
  - 認識サーバーが、WAV 以外・大きすぎる・長すぎる送信を断るようにしました。話した内容をログに残さないようにしました
- `update.bat` で最新版に入れ替えられるようになりました
- ライセンスを Apache License 2.0 にしました

## 1.0.1

- 認識履歴の ▶ で、そのときの録音を聞き直せるようになりました
- 辞書に「定型文」を追加。合言葉だけを言うと、登録した文（メールアドレス・住所など）が入ります
- 設定画面を「よく使う設定」と「詳しい設定」に分けました
- 辞書に登録した言葉が、一覧の先頭に出るようにしました
- 録音キーを「右Alt」のように読みやすく表示するようにしました

## 1.0.0

- 最初の版
