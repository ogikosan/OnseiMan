# 変更点

## 1.2.0

- GitHub に新しい版が出ると、画面の上に「新しい版があります」と出るようにしました（起動したときと、1 日 1 回確かめます）
  - 何が変わったかも見られます。「今すぐ更新」を押すと、確認のあと OnseiMan が自分で終了して入れ替え、起動し直します
  - タスクトレイのメニューも「新しい版にする」に変わります
  - 設定・辞書・履歴はそのまま残り、前の版は `backup` フォルダに残ります
- `update.bat` が、ほかの場所に置いた OnseiMan が動いているだけでも「動いています」と止まっていたのを直しました
- この版にするときだけは、これまでどおり `update.bat` で入れ替えてください（次からはお知らせから更新できます）

## 1.1.3

- `update.bat` で、前の版を `backup` に残すときに、OnseiMan 専用の Python（約80MB）までコピーしていたのをやめました。
  遠隔操作（SSH）から更新したときに、ここで止まることがありました

## 1.1.2

- タスクトレイのアイコンを押すたびに、画面が何個も開いていたのを直しました。開いていれば、その画面を前に出します
- 学習候補の「今後出さない」をやめて「×」にしました。×で消しても、同じ直しをまたしたら候補に出ます（自動では登録しません）
  - 押したあとに出る「元に戻す」と、学習候補の画面の「消した候補」から、いつでも戻せます
  - 前の版で「今後出さない」にしたものも「消した候補」に入り、戻せます

## 1.1.1

- `start_client.bat` で起動したときに準備が必要だと、「何かキーを押してください」で止まっていたのを直しました。
  準備が済んだら、そのまま起動します（うまくいかなかったときだけ止まって、内容を見せます）

## 1.1.0

- 辞書（優先語・置き換え・言いよどみ・定型文）を、何台かのパソコンで自動で合わせられるようにしました。
  「設定」→「辞書をほかのパソコンと合わせる」で、預け先を選びます
  - 認識役のパソコンに預ける（「別のパソコン」で認識しているとき）
  - 同期フォルダに置く（OneDrive・Google ドライブ・Dropbox など）
  どれか 1 台で登録・削除すると、ほかのパソコンにも入ります。それぞれで登録していた言葉は、初めて合わせたときに足し合わされます
- 認識役のパソコンも新しい版にしてください（辞書を預かれるようになります）

## 1.0.9

- 準備のときに取ってきた部品の控えを、ユーザーのフォルダに残さないようにしました
  （これまでは `%LOCALAPPDATA%\uv` などに 100MB ほど残っていました。Python 本体は、前からこのフォルダの中だけです）

## 1.0.8

- 認識役のパソコンが、iPhone で録音した音声（M4A）も受け付けるようにしました。
  iPhone の「ショートカット」から声を送って、文字にしてもらえます（Mac 用の `はじめに.md` に作り方があります）
- 認識役に長い音声（30 秒以上など）が送られてきても、話の切れ目で区切って最後まで文字にするようにしました
  （これまでは何も返ってきませんでした）

## 1.0.7

- Mac を認識役にするとき、`server_mac.command` をダブルクリックするだけでよくなりました（Python を入れなくてよくなりました）
  やめるときは `server_mac_remove.command`
- 別の Windows を認識役にするときは、`server_windows.bat` をダブルクリックするだけになりました
- 配る zip を、Windows 用と Mac 用に分けました（Mac 用は認識役に要るものだけ）

## 1.0.6

- 何台か見つかったとき、「いつもこれにする」で、ふだん使うパソコンを選べるようにしました
  （止まっているときだけ、ほかのパソコンを使います。初めて探したときは、返事がいちばん速いパソコンを選びます）
- 設定画面に「相手のパソコンの準備のしかた」を追加しました。見つからなかったときは自動で開きます
- 相手のサーバーがデータを読み込み中のときは「準備中」と出すようにしました

## 1.0.5

- 「別のパソコン」を選ぶと、自動でサーバーを探して、見つかったものを使うように設定します（チェックも保存もいりません）
- 同じパソコンが Tailscale と家のネットワークの 2 つの行き方で見つかっても、1 つにまとめます
  （Tailscale のアドレスを使います。家でも外でも使えます）。Tailscale だけ・家のネットワークだけでも使えます
- サーバーの一覧に、パソコンの名前と IP を両方出します。名前はクリックで好きな名前に変えられます
- 画面右上に「Mac mini で認識」のように、使っているパソコンの名前を出します
- 黙ったら自動で入力する設定を、初期設定ではオフにしました（考えている間に入力されてしまうため）
- サーバー（start_server）を起動したとき、そのパソコンのアドレスを表示します

## 1.0.4

- 準備が済んでいないときは、`start_client.bat` が先に自動で準備するようにしました
- `update.bat` の最後に意味のないエラーが 1 行出ることがあったのを直しました
- 道具をダウンロードできないとき（入っている Python で代用する経路）でも、部品が入るようにしました

## 1.0.3

- `install_client.bat` が失敗する不具合を直しました（1.0.1・1.0.2 で、部品が入らず日本語の行がエラーになっていました）
- Python を自分で入れなくてもよくなりました。必要なものは、OnseiMan のフォルダの中に自動で用意します
- サーバー用（Windows）の準備も同じ仕組みにしました

## 1.0.2

- 安全のための直し
  - 設定画面を、ほかのサイトから操作・のぞき見・埋め込みされないようにしました
  - 認識用のデータが本物かどうかを、ダウンロードのあとに確かめるようにしました
  - 認識サーバーが、WAV 以外・大きすぎる・長すぎる送信を断るようにしました。話した内容をログに残さないようにしました
- `update.bat` で最新版に入れ替えられるようになりました
- ライセンスを Apache License 2.0 にしました

## 1.0.1

- 認識履歴の ▶ で、そのときの録音を聞き直せるようになりました
- 辞書に「定型文」を追加。合言葉だけを言うと、登録した文（メールアドレス・住所など）が入ります
- 設定画面を「よく使う設定」と「詳しい設定」に分けました
- 辞書に登録した言葉が、一覧の先頭に出るようにしました
- 録音キーを「右Alt」のように読みやすく表示するようにしました
