# OnseiMan の入れ方

話した言葉を、カーソルのある場所に文字で入れる Windows のアプリです。

> 自分でやるのが面倒なら、このフォルダを Claude などの AI に渡して
> 「AGENTS.md を読んで入れて」と頼めば、代わりにやってくれます。

---

## 1. Windows に入れる（これだけで使えます）

**いちばん簡単なのは、インストーラーです。** GitHub の「Releases」から `OnseiMan-Setup-…exe` を取ってきて、
ダブルクリックするだけです（入れる場所を選んで「インストール」。数分かかります）。
スタートメニューに「OnseiMan」ができます。消すときは、Windows の「アプリ」から「OnseiMan」をアンインストールします
（設定・辞書・履歴は残ります）。

zip で入れるときは、次のとおりです。

1. このフォルダを好きな場所に置く
2. `install_client.bat` をダブルクリック（1〜数分）
3. `start_client.bat` をダブルクリック → タスクバーにアイコンが出ます
4. 初回だけ、声を文字にするための部品（約0.7GB）を自動でダウンロードします（数分。途中で止まっても、次は続きから）

声を文字にするのは、聞き間違いの少ない Haas-ja です。GPU は要りません。

Python などを自分で入れる必要はありません。必要なものは、このフォルダの中に自動で用意します
（パソコン全体には何も入れません）。インターネットにつながっている必要があります。

## 2. 使う

1. 文字を入れたい場所をクリック
2. **右Alt** を押して離して、話す
3. もう一度 **右Alt** → 文字が入ります

くわしくは、アプリの画面の「使い方」タブを見てください。

### AI で整える（使いたい人だけ）

話した文を AI に渡して、言い直しや「えーと」を整えた、読みやすい文にできます。
「設定」→ 左の「AI で整える」で、頼む AI（GPT・Claude・Gemini・自分で動かす AI）を選び、API キーを貼り付けて「試す」。

- 「話し終えたら、いつも AI で整える」をオンにすると、毎回整えます。整えているあいだに録音キーをもう一度押すと、待たずに整える前の文が入ります
- 「AI のキー」を決めると、そのキーで話したときだけ整えます。文を選んでからそのキーで「敬語にして」などと話すと、選んだ文を書き換えます
- AI を使うときだけ、文字（音声ではありません）を選んだ会社に送ります。API キーは使った分だけ料金がかかります（整える 1 回は 1 円もしません）
- Claude の月額プラン（Pro など）は、ほかのアプリからは使えません。Claude を使うときは API キーを作ってください

## 新しい版に入れ替えるとき

新しい版が出ると、OnseiMan の画面の上に「新しい版があります」と出ます（起動したときと、1 日 1 回確かめます）。
「今すぐ更新」を押すと、OnseiMan が自分で終了して入れ替え、起動し直します。

自分で入れ替えるときは:

1. タスクバーの OnseiMan のアイコンを右クリック →「終了」
2. `update.bat` をダブルクリック（インターネットから最新版を取ってきて入れ替えます）
3. `start_client.bat` で起動（必要なら、起動の前に自動で準備をやり直します）

設定・辞書・履歴はそのまま残ります。前の版は `backup` フォルダに残ります。
何が変わったかは `変更点.md` に書いてあります。

### 前の版の、もう使わないデータを消す

新しい版にしても、前の版で使っていたデータやファイルは、そのまま残ります
（たとえば 1.2.26 以前の聞き取りのデータ、約 900MB）。`cleanup_old.bat` をダブルクリックすると、
消すものと大きさを並べて、「消してよいですか」と聞いてから消します。
設定・辞書・履歴と、いまの聞き取りの部品には触りません。

`update.bat` が無い古い版のときや、うまく動かないときは、新しい zip の中身を
いま使っているフォルダに上書きでコピーしてから、`start_client.bat` を実行してください。

## 3. もっと速くしたいとき（なくても大丈夫）

ふだん使うパソコンが遅いときは、**家にある別のパソコン**（Mac でも Windows でも）に声を文字にする役を任せられます。
（聞き取りの Haas-ja は、ふつうのパソコンの CPU でも 1 回 1 秒以内なので、たいていは要りません。
Mac に任せると、Apple の GPU で 1 回 0.1 秒ほどになります）

ふだん使うパソコンから、任せる側のパソコンに何かを入れることはしません。
任せる側のパソコンの前で、次の準備を 1 回だけしてください（ほかの人のパソコンなら、先にその人に聞いてください）。

**任せる側のパソコンで**（どちらか）

- **Mac**：Mac 用の zip（`OnseiMan-…-Mac.zip`）を Mac で展開して、`server_mac.command` をダブルクリック（10分ほど）。
  「準備できました」と出たら完了。Mac を起動するたびに自動で動きます。Python は要りません。
  くわしくは、Mac 用の zip に入っている `はじめに.md` を見てください。
- **Windows**：このフォルダをコピーして、`server_windows.bat` をダブルクリック。
  Python を自分で入れる必要はありません。Windows のファイアウォールの確認が出たら「許可」。
  使うあいだは、出てきた黒い窓を閉じないでください。

**ふだん使うパソコンで**

アプリの「設定」→「声を文字にする場所」で **別のパソコン** を選ぶだけです。
自動で探して、見つかったパソコンを使うように設定します。名前はクリックで変えられます。
何台か見つかったときは、「いつもこれにする」で、ふだん使うパソコンを選べます（止まっているときだけ、ほかを使います）。
任せる側のパソコンの準備のしかたは、アプリの設定画面にも出ています。

見つからないときは、2台が同じ Wi-Fi（または同じ Tailscale）につながっているか確かめてください。

## 4. 何台かのパソコンで使うとき（辞書を合わせる）

どれか 1 台で登録した言葉（辞書・定型文）を、ほかのパソコンにも自動で入れられます。
アプリの「設定」→「辞書をほかのパソコンと合わせる」で、どちらかを選びます（どのパソコンでも同じものを選んでください）。

- **認識役のパソコンに預ける**：「別のパソコン」で認識しているとき。ほかに何もいりません
- **同期フォルダに置く**：OneDrive・Google ドライブ・Dropbox などを使っているとき。見つかった同期フォルダがボタンで出ます

それぞれのパソコンで登録していた言葉は、初めて合わせたときに足し合わされます（消えません）。
