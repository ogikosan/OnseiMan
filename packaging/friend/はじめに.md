# OnseiMan の入れ方

話した言葉を、カーソルのある場所に文字で入れる Windows のアプリです。

> 自分でやるのが面倒なら、このフォルダを Claude などの AI に渡して
> 「AGENTS.md を読んで入れて」と頼めば、代わりにやってくれます。

---

## 1. Windows に入れる（これだけで使えます）

1. このフォルダを好きな場所に置く
2. `install_client.bat` をダブルクリック（数分）
3. `start_client.bat` をダブルクリック → タスクバーにアイコンが出ます
4. 初回だけ、声を文字にするためのデータ（約840MB）を自動でダウンロードします

Python が無いと言われたら、https://www.python.org から Python 3.11 を入れてください
（入れるときに「Add python.exe to PATH」にチェック）。

## 2. 使う

1. 文字を入れたい場所をクリック
2. **右Alt** を押して離して、話す
3. もう一度 **右Alt** → 文字が入ります

くわしくは、アプリの画面の「使い方」タブを見てください。

---

## 新しい版に入れ替えるとき

1. タスクバーの OnseiMan のアイコンを右クリック →「終了」
2. `update.bat` をダブルクリック（インターネットから最新版を取ってきて入れ替えます）
3. `start_client.bat` で起動

設定・辞書・履歴はそのまま残ります。前の版は `backup` フォルダに残ります。
何が変わったかは `変更点.md` に書いてあります。

`update.bat` が無い古い版のときは、新しい zip の中の `OnseiMan` フォルダの中身を、
いま使っているフォルダに上書きでコピーしてから、`install_client.bat` をもう一度実行してください。

---

## 3. もっと速くしたいとき（なくても大丈夫）

ふだん使うパソコンが遅いときは、**家にある別のパソコン**（Mac でも Windows でも）に声を文字にする役を任せられます。

**任せる側のパソコンで**（どちらか）

- **Mac**：このフォルダをコピーして、ターミナルでこのフォルダに移動し、次を実行（10分ほど）
  ```
  bash server/setup_macos.sh
  ```
  最後に `{"status":"ok", ...}` と出たら完了。Mac を起動するたびに自動で動きます。
  （Python が無いと言われたら、先に `brew install python@3.11`）
- **Windows**：このフォルダをコピーして、`server\install_server_windows.bat` → `server\start_server.bat`。
  Windows のファイアウォールの確認が出たら「許可」。

**ふだん使うパソコンで**

アプリの「設定」→「声を文字にする場所」で **別のパソコン** を選び、
**サーバーをさがす** → 見つかったパソコンにチェック →「設定を保存」。

見つからないときは、2台が同じ Wi-Fi（または同じ Tailscale）につながっているか確かめてください。
