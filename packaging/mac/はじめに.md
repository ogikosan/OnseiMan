# OnseiMan（Mac を認識役にする）

OnseiMan は、話した言葉をカーソルの場所に文字で入れる **Windows** のアプリです。
この Mac は、その Windows から送られた声を文字にする「認識役（サーバー）」になります。
Mac で文字を入力するアプリではありません。

Windows のパソコンから、この Mac に何かを入れることはしません。
この Mac の前で、この Mac を使っている人が、次の準備を 1 回だけしてください。

---

## 1. 準備する（はじめての 1 回だけ。10分ほど）

1. この `OnseiMan` フォルダを、好きな場所（「書類」など）に置く
2. `server_mac.command` をダブルクリック
3. 「準備できました」と出たら完了。窓は閉じて大丈夫です

Python などを自分で入れる必要はありません。必要なものと、認識用のデータ（約840MB）は、
このフォルダの中に自動で用意します。インターネットにつながっている必要があります。
一度済めば、Mac を起動するたびに自動で動きます（ログインしているあいだ）。

### 「開けません」と出たとき

インターネットから取ってきたファイルなので、Mac が止めることがあります。

- `server_mac.command` を **右クリック（または control を押しながらクリック）→「開く」→「開く」**
- それでも開けないときは、「システム設定」→「プライバシーとセキュリティ」の下の方にある
  「このまま開く」を押してから、もう一度ダブルクリック
- 最後の手段：「ターミナル」を開き、`bash ` と打って（最後に空白）、`server_mac.command` を
  ターミナルの窓に引っ張って入れ、return

## 2. Windows から使う

Windows の OnseiMan の「設定」→「声を文字にする場所」で **別のパソコン** を選ぶと、自動で見つけて使います。
2 台が同じ Wi-Fi（または同じ Tailscale）につながっている必要があります。

## 新しい版にする

新しい Mac 用の zip の中身を、このフォルダに上書きでコピーして、もう一度 `server_mac.command` をダブルクリックします。
認識用のデータは取り直しません。

## やめる

`server_mac_remove.command` をダブルクリックすると、止まって、自動で動かなくなります。
フォルダはそのまま残るので、いらなければフォルダごとゴミ箱へ入れてください。
