# OnseiMan（Mac を認識役にする）

OnseiMan は、話した言葉をカーソルの場所に文字で入れる **Windows** のアプリです。
この Mac は、その Windows から送られた声を文字にする「認識役（サーバー）」になります。
Mac で文字を入力するアプリではありません。

Windows のパソコンから、この Mac に何かを入れることはしません。
この Mac の前で、この Mac を使っている人が、次の準備を 1 回だけしてください。

---

## 1. 準備する（はじめての 1 回だけ。10分ほど）

1. この `OnseiMan` フォルダを、好きな場所（「書類」など）に置く
2. `server_mac.command` をダブルクリック
3. 「準備できました」と出たら完了。窓は閉じて大丈夫です

Python などを自分で入れる必要はありません。必要なものと、認識用のデータ（約840MB と、
聞き間違いの少ない Haas-ja 約0.7GB）は、このフォルダの中に自動で用意します。インターネットにつながっている必要があります。
Haas-ja は Apple の GPU で動くので、1 回 0.1 秒ほどで文字にします。
一度済めば、Mac を起動するたびに自動で動きます（ログインしているあいだ）。

### 「開けません」と出たとき

インターネットから取ってきたファイルなので、Mac が止めることがあります。

- `server_mac.command` を **右クリック（または control を押しながらクリック）→「開く」→「開く」**
- それでも開けないときは、「システム設定」→「プライバシーとセキュリティ」の下の方にある
  「このまま開く」を押してから、もう一度ダブルクリック
- 最後の手段：「ターミナル」を開き、`bash ` と打って（最後に空白）、`server_mac.command` を
  ターミナルの窓に引っ張って入れ、return

## 2. Windows から使う

Windows の OnseiMan の「設定」→「声を文字にする場所」で **別のパソコン** を選ぶと、自動で見つけて使います。
2 台が同じ Wi-Fi（または同じ Tailscale）につながっている必要があります。

## iPhone から使う（なくても大丈夫）

iPhone の「ショートカット」で、話した言葉を文字にしてクリップボードに入れられます。
iPhone とこの Mac が、同じ Wi-Fi か同じ Tailscale につながっている必要があります。

1. 「ショートカット」アプリで新しいショートカットを作り、次の 4 つを順に足す
   - 「オーディオを録音」（形式は「AAC（M4A）」のまま）
   - 「URL の内容を取得」：URL に `http://<この Mac のアドレス>:8765/transcribe`、方法を「POST」、
     本文を「フォーム」にして、項目名 `audio`・種類「ファイル」に「録音したオーディオ」を入れる
   - 「辞書の値を取得」：キーに `text`
   - 「クリップボードにコピー」
2. 「設定」→「アクセシビリティ」→「タッチ」→「背面タップ」（またはアクションボタン）に、このショートカットを割り当てる

この Mac のアドレスは、`server_mac.command` の最後に表示されます。長く話しても、区切って最後まで文字にします。

## 辞書を預かる

Windows の OnseiMan で「辞書をほかのパソコンと合わせる」→「認識役のパソコンに預ける」を選ぶと、
この Mac が辞書を預かり、何台かの Windows で同じ辞書を使えます。預かった辞書は `server_data` フォルダにあります。

## 新しい版にする

新しい `onseiman-server-macos-arm64` を `onseiman-server` に上書きコピーして、もう一度 `server_mac.command` をダブルクリックします。
認識用のデータは取り直しません。

## やめる

`server_mac_remove.command` をダブルクリックすると、止まって、自動で動かなくなります。
フォルダはそのまま残るので、いらなければフォルダごとゴミ箱へ入れてください。
