                Tailscale と家のネットワークから、OnseiMan のサーバーを探して、見つかったものを自動で使います。名前はクリックで変えられます
              

              

              

                相手のパソコンの準備のしかた（はじめて使うとき）
                

                  
声を文字にする役のパソコンには、OnseiMan のサーバーと、認識用のデータ（約840MB）が要ります。

                  
このパソコンから、相手のパソコンに入れることはしません。
                  相手のパソコンの前で、そのパソコンを使っている人（自分のパソコンなら自分）が、次の準備をしてください。
                  ほかの人のパソコンを使うときは、先にその人に聞いてください。

                  
    
                    
  1. 相手のパソコンに OnseiMan を置く。GitHub の「Releases」から、Windows なら OnseiMan-…-Windows.zip、
                      Mac なら OnseiMan-…-Mac.zip を取ってきて展開する（このフォルダをコピーしても同じ）
    2. 
                    
  2. Windows のとき：server_windows.bat をダブルクリック。
                      はじめては、そのパソコンに必要なものとデータ（約840MB）をダウンロードするので、数分〜10分かかります。「ファイアウォール」の確認が出たら「許可」。
                      使うあいだは、出てきた黒い窓を閉じないでください。
    3. 
                    
  3. Mac のとき：server_mac.command をダブルクリック（Python は要りません）。
                      データのダウンロードを含めて 10分ほどかかります。「開けません」と出たら、右クリック→「開く」。
                      一度済めば、Mac を起動するたびに自動で動きます。やめるときは server_mac_remove.command。
    4. 
                    
  4. こちらに戻って「サーバーをさがす」を押す
    5. 
                  

                  
見つからないとき：2 台が同じ Wi-Fi（または同じ Tailscale）につながっているか、
                  相手のパソコンが起動していて、サーバーの窓が開いているかを確かめてください。
                  「準備中」と出るときは、データを読み込んでいるところです。少し待ってからもう一度さがしてください。

困ったとき

          

            

              文字が入らない
              
入れたい場所をクリックしてから話してください。管理者で動いているアプリには入れられないので、Ctrl+V で貼り付けてください（コピーしてあります）。

            

            

              何と言ったか聞き直したい
              
「認識履歴」の ▶ を押すと、そのときの録音を聞けます（新しい100件まで）。

            

            

              メールアドレスや住所を毎回言うのが面倒
              
「辞書」→「定型文」で合言葉と文を登録すると、合言葉だけを言ったときにその文が入ります。

            

            

              同じ言葉をいつも間違える
              
「辞書」で、正しい言葉と聞き間違えた言い方を登録します。「認識履歴」で間違えた行を選んで「辞書に登録」もできます。

            

            

              うまくいかなかった録音をやり直したい
              
「認識履歴」で行を選んで「もう一度文字にする」を押します。失敗した行は「再試行」でも同じです。

            

            

              左の印が赤い
              
マイクの音が来ていません。ミュートや「設定」のマイクを確かめてください。

            

            

              表示の場所を変えたい
              
カプセルをドラッグすると、次からその場所に出ます。ダブルクリックで元に戻ります。

            

            

              動画や音楽の音が消える
              
録音中だけ、ほかのアプリの音を消しています。「設定」でオフにできます。
