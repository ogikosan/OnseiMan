PROJECT OVERVIEW

OnseiMan

話した言葉を、カーソルのある場所に文字で入れる Windows 用の音声入力アプリ。声を文字にするのは、このパソコンか、別のパソコン（Mac など）。

現状

  • 右Alt を押して話し、もう一度押すと入力。長く話しても、話しながら区切って認識するので消えない。
  • 録音中はカプセル型の表示（ドラッグで場所を固定）。入力後は「取り消す」。録音中はほかのアプリの音を消す。
  • 辞書は「正しい言葉」を登録するだけ。合言葉で決まった文を入れる「定型文」。履歴では録音を聞き直せて、「もう一度文字にする」もできる。
  • 設定は、左の項目（基本・声を文字にする場所・録音・文の仕上げ・AI で整える など）を押して切り替える。AI で整えるときは GPT・Claude・Gemini・自分で動かす AI から選べる。
  • GitHub（ogikosan/OnseiMan、公開）に置いた。友達は update.bat で最新版に入れ替えられる（設定・辞書・履歴は残る）。zip で渡すこともできる。

友達向けの説明（packaging/friend/はじめに.md）は「Windows だけで使う」が基本で、速くしたい人だけ別のパソコン（Mac / Windows）をサーバーにする。

まだ: サーバーのセットアップと Windows の初回インストールを、まっさらなパソコンで試していない。

使い方

起動

start_client.bat

初めてのときは先に install_client.bat。画面の「使い方」タブに操作の説明がある。

友達に渡す

python packaging\make_friend_package.py

build_dist\OnseiMan-<版>-Windows.zip と -Mac.zip ができる。自分の設定・辞書・履歴・録音は入らない。

主要な判断

  • 話しながら区切って認識する — モデルは約 30 秒を超えると結果が空になるため。待ち時間も短くなる。
  • 区切りの長さを辞書の言葉の数で変える — 言葉のヒントも同じ枠を使い、多いと文が欠けるため（実測）。
  • 録音キーは右Alt のまま、Alt の押下・離しを丸ごとアプリに見せない — メニューが開いてカーソルが外れるのを防ぐ。
  • 友達には exe でなくソース一式 — サーバー側（Mac）は結局 Python が要るため。手順は人向けと AI 向けの 2 つ。
